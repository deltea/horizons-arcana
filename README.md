1. main menu
  - shake box to play

2. day X displays
3. blind box drops in

5. open box or not phase
6. resolve box
  - if blow up, minus health and move on to next box
  - if prize inside, move to prize box
  - if not open, move to trash can
7. repeat open box
8. day over, calculate how much money earned
